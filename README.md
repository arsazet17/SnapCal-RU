# SnapCal RU v1.0

Русская версия исходного Android-приложения [ghostwan/food-calories](https://github.com/ghostwan/food-calories).
Основа: commit `12409267166196efa3f18413b490550d5e8dbac1`.

Функции: анализ фотографии из камеры или галереи; описание еды текстом или голосом;
калории, белки, жиры, углеводы и клетчатка; дневник и история; избранное,
профиль, замеры, напоминания, виджеты, список покупок, отчёты и рекомендации ИИ.
Интерфейс и запросы к ИИ настроены на русский язык. Для голосового ввода нужна
установленная служба распознавания русской речи. Экран внешней службы Google
или Android может использовать язык системных настроек.

## Начало работы

Откройте «Добавить еду» → значок настроек → введите собственный Gemini API-ключ
из [Google AI Studio](https://aistudio.google.com/apikey) → «Сохранить».
По умолчанию используется gemini-2.5-flash. Доступность моделей и региона зависит от Google.
Ключ можно удалить, очистив поле и сохранив настройки.
Подписок, встроенных покупок и общего ключа разработчика нет.
Квоты и возможную плату за Gemini определяет Google для аккаунта владельца ключа.

В результате анализа нажмите на продукт и измените его название, количество
(например, «150 г») и калории. При изменении количества в тех же единицах калории
масштабируются автоматически, пока вы не изменили их вручную. БЖУ при ручной
правке оцениваются пропорционально изменению калорий всего блюда. При замене
продукта используйте «Пересчитать с ИИ»: например, «это гречка 200 г, а не рис».
После исправления нажмите «Сохранить в дневник» или «Сохранить изменения».
Все оценки по фотографии приблизительные.

## Хранение ключа

Ключ не читается из local.properties, ресурсов или BuildConfig и не входит в APK.
На устройстве он шифруется AES-256-GCM с ключом Android Keystore. Зашифрованный
файл находится в noBackupFilesDir; системные резервные копии приложения отключены.
Резервная копия питания на Google Диске API-ключ не содержит. Ключ передаётся
Gemini по HTTPS в заголовке x-goog-api-key, а не в URL. Тела ошибок сервера в
интерфейс не выводятся. При анализе Google получает фотографию или описание еды.

## Сборка

Нужны JDK 21, Android SDK Platform 35 и Build Tools 34.0.0 (версия по умолчанию
AGP 8.7.3), platform-tools. Gradle Wrapper 8.9 включён в проект.
Укажите SDK через ANDROID_HOME или sdk.dir в local.properties. Не помещайте
Gemini API-ключ в настройки сборки.

```sh
./gradlew --no-daemon :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Для подписанной установочной release-сборки создайте собственный keystore с alias
snapcal-ru и задайте переменные окружения SNAPCAL_KEYSTORE и SNAPCAL_STORE_PASSWORD.
Приватный ключ подписи сохраните для дальнейших обновлений приложения.

```sh
./gradlew --no-daemon :app:assembleRelease :app:testDebugUnitTest :app:lintRelease
```

Результат: app/build/outputs/apk/release/app-release.apk. Без переменных подписи
Gradle создаёт неподписанный release APK. Для установки используйте подписанный
APK, проверьте его через apksigner verify. Android 8.0 (API 26) или новее.
Идентификатор com.ghostwan.snapcal.ru позволяет установить RU рядом с оригиналом.
Существующий дневник другого пакета автоматически не переносится.

Дополнительные функции Health Connect и Google Диска зависят от системных
сервисов, разрешений и настройки Google OAuth для нового package name и сертификата.
Облачное резервное копирование не проверялось с пользовательским Google-аккаунтом.
