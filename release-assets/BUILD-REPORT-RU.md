## Изменения

Сохранены потоки анализа по фотографии, текстового и голосового ввода, расчёт
калорий и БЖУ, дневник и история. Переведены интерфейс, настройки, уведомления,
виджеты, подписи графиков и пользовательские сообщения об ошибках. Язык
приложения и голосового ввода — русский, ответы Gemini запрашиваются по-русски.
В редакторе продукта можно исправить название, количество и калории.
При ручной правке количества калории масштабируются для одинаковых единиц;
БЖУ приблизительно масштабируются по общей калорийности. Для замены продукта
предусмотрен полный пересчёт с ИИ. Ошибочные и отрицательные значения блокируются.
Сериализация названий в дневнике корректно обрабатывает кавычки и обратные слеши.

Ключ вводится пользователем в маскированное поле и хранится в noBackupFilesDir,
зашифрованный AES-256-GCM с ключом Android Keystore. Можно удалить ключ из
настроек. Он отправляется только Gemini через HTTPS-заголовок x-goog-api-key.
Нет встроенных покупок и подписок. Использование собственного ключа регулируется
квотами и условиями Google.

Исправлены обнаруженные Lint проблемы исходника: обработка отзыва разрешения
уведомлений и использование API виджета только на поддерживающих его Android.
Для плитки быстрых настроек сохранена старая ветка API 26–33 и PendingIntent
на API 34+, с точечной пометкой совместимости для Lint.

## Установка и ключ

Установите SnapCal-RU-v1.0.apk, разрешив установку из выбранного источника.
Откройте «Добавить еду» → значок настроек → введите свой Gemini API-ключ →
«Сохранить». Для исправления продукта нажмите на него в результатах;
для замены с новым расчётом БЖУ используйте «Пересчитать с ИИ».
